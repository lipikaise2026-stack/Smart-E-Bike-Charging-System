# Smart E-Bike Charging System with Dual-Battery Swapping

## Project Overview
An academic major project exploring a dual-battery charging system for electric bikes. The proposed system combines solar energy and back-EMF-based energy generation to support battery charging and automatic battery changeover.

## Key Features
- Dual-battery arrangement for power supply and charging.
- Solar-assisted battery charging.
- Back-EMF-based energy generation.
- ESP32-based monitoring concept.
- Relay-based automatic battery switching.
- Voltage and current sensing.
- LCD status display and Telegram notifications.

## Proposed Technologies
- ESP32
- Arduino / Embedded C
- Solar panel
- DC generator
- MPPT DC-DC converter
- Voltage and current sensors
- Relay module
- LCD display
- Telegram notifications

## Project Workflow
1. One battery supplies power to the vehicle.
2. The second battery is considered for charging.
3. Solar and back-EMF-based sources support the proposed charging arrangement.
4. The monitoring and relay-switching system manages battery status and changeover.
